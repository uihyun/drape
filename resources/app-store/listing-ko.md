# 스토어 리스팅 — 한국어

글자수 제한은 각 항목에 표기. 초과하면 제출 자체가 반려되므로 하드 캡으로 취급.

## App Store Connect

**이름** (≤30):

```
drape: 내 옷장과 트라이온
```

**부제** (≤30) — 이름에 이미 있는 *옷장* / *트라이온* 은 빼고, 새 검색어를 넣는다:

```
AI 스타일리스트와 코디 기록
```

**프로모션 텍스트** (≤170 — 빌드 없이 수정 가능, 캠페인용):

```
사진만 찍으면 옷장이 만들어지고, 사기 전에 내 몸에 입혀볼 수 있어요. AI 스타일리스트가 가진 옷으로 코디도 짜줘요.
```

**키워드** — 바꾸지 마세요. 현재 라이브 값이 이 저장소에 없습니다 (ASC에 직접 입력됨).
순위는 키워드마다 쌓이므로, 무엇을 대체하는지 모르는 채로 교체하면 유입을 잃을 수 있습니다.
꼭 필요한 변경은 하나뿐입니다: 새 부제(`AI 스타일리스트와 코디 기록`)에 들어간 단어가
라이브 키워드에 있으면 그것만 빼세요 — 이름·부제·키워드는 합쳐서 색인되므로 중복은 낭비입니다.
라이브 값을 `store-metadata.md`에 먼저 기록해두면 다음부터 이 문제가 없습니다.

```
(ASC의 현재 값 유지)
```

**설명** (≤4000):

```
옷장 전체가, 이제 손안에.

가진 옷을 한 장씩 찍기만 하면 drape가 배경을 깔끔하게 지우고 카테고리·색·계절까지 자동으로 정리해 디지털 옷장을 만들어줘요. 전신 사진 몇 장이면 AI 가상 피팅으로 무엇이든 입어볼 수 있어요. 사기 전에, 입기 전에 — 진짜 내 얼굴과 몸에 걸친 모습을 미리 확인하세요.

마음에 드는 누군가의 착장? 그 룩을 통째로 내 몸에 입혀 보세요.

• 디지털 옷장 — 찍기만 하면 배경 제거부터 카테고리·색·계절 태그까지 자동으로.
• 가상 피팅 — 한 벌이든 코디 전체든, 내 얼굴과 포즈를 그대로 살리는 AI로.
• AI 스타일리스트 — 내가 가진 옷으로만 코디를 짜주는 나만의 스타일리스트.
• OOTD 캘린더 — 매일의 착장을 기록하고 나만의 스타일을 쌓아가요.
• 코디 & 보드 — 옷을 조합해 룩을 짜고, 무드보드로 영감을 모아요.
• 트렌드 — 매주 월요일 새 이슈로, 이번 주 뜨는 스타일·색·브랜드를.

옷장, 피팅룸, 스타일 다이어리. 전부 drape 안에.
```

**새로운 기능** (≤4000) — 2.1.1:

```
• AI 스타일리스트: 4명 중 한 명을 고르면 내 옷장으로 코디를 제안하고,
  탭 한 번으로 내 모습에 입혀볼 수 있어요.
• 트렌드: 매주 월요일 새 이슈로 이번 주 뜨는 스타일·색·브랜드를 보여줘요.
• 쇼핑 앱에서 상품 페이지를 drape로 공유하면 사기 전에 어울리는지
  확인할 수 있어요.
• 영어·한국어·일본어에 스페인어와 프랑스어가 더해졌어요.
• 슬라이드 여러 장 대신, 화면을 짚어가며 알려주는 둘러보기로 바뀌었어요.
• 옷장을 두 손가락으로 키우고 줄이고, 색·카테고리·착용 횟수로 정렬하고,
  여러 벌을 한 번에 등록할 수 있어요.
```

## Google Play Console

**앱 이름** (≤30):

```
drape: 내 옷장과 트라이온
```

**간단한 설명** (≤80):

```
옷장을 디지털로 만들고, AI로 입어보고, 매일의 코디를 기록해요.
```

**자세한 설명** (≤4000) — 위 App Store 설명을 그대로 사용.

**출시 노트** (Play, ≤500자) — 2.1.1:

App Store는 4000자를 받지만 **Play는 500자**라, 같은 글을 자른 게 아니라
항목을 줄인 별도 버전입니다. 약한 두 항목은 마지막 한 줄로 합쳤습니다.

```
• AI 스타일리스트: 넷 중 한 명을 고르면 내 옷장으로 코디를 짜주고, 탭 한 번으로 입어볼 수 있어요.
• 트렌드: 매주 월요일 새 이슈로 이번 주 뜨는 스타일·색·브랜드를 보여줘요.
• 쇼핑 앱 상품 페이지를 drape로 공유하면 사기 전에 어울리는지 확인해요.
• 스페인어와 프랑스어가 더해졌어요.
• 슬라이드 대신 화면을 짚어주는 둘러보기. 두 손가락으로 옷장 크기 조절, 새 정렬, 여러 벌 한 번에 등록.
```
