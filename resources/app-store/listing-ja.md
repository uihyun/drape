
```

```

**説明** (≤4000):

```
drape は、あなたの服が住む場所です。

全身写真を2〜3枚登録するだけで、着る前・買う前に自分の体で試着できます。
持っている服を一着ずつ撮れば、背景を切り抜き、タグを付けて整理します —
カタログではなく、あなた自身のクローゼットになります。

自分の体で試着
• 全身写真を2〜3枚登録すれば、どんな服でも試着できます。
• モデルではなく自分の顔と体なので、結果が自分らしく見えます。
• 毎日5回無料。友達を招待すると、お互いに10回ずつ追加されます。

デジタルクローゼット
• 一着に一枚。背景を消し、カテゴリ・色・季節・スタイルを自動でタグ付け。
• 急いでいるときはコーデ写真を一枚。その中の服を一つずつ検出します。
• タグ・ブランド・色で検索と絞り込み。二本指でサイズを変えて、
  一覧で多く見るか、大きく詳しく見るか選べます。

あなた専用のAIスタイリスト
• スタイリストを選ぶと、手持ちの服だけでコーデを提案します。
• 好きなスタイルと避けたい色を伝えてください。入力した好みが
  推測より優先されます。
• 気に入ったコーデは保存して、いつでもまた試着できます。

OOTDカレンダー
• 写真一枚で一日が記録され、カレンダーが自然に埋まっていきます。
• よく手に取る服と、忘れていた服が見えてきます。

トレンド
• 毎週月曜に新しい号。今週伸びているスタイル・色・ブランドを、
  メンバーが実際に着ている服から選んでお届けします。

他の人のクローゼットを見る
• トレンドでコーデを開くと投稿者が分かり、その人の公開クローゼットを見られます。
• その服を自分に試着して、気に入ったら保存できます。

drape は無料で始められます。試着は毎日回復する回数を使います。
```

**新機能** (≤4000) — 2.1.0:

```
• AIスタイリスト：4人から選ぶと、クローゼットからコーデを提案。
  ワンタップで自分の姿に試着できます。
• トレンド：毎週月曜の新しい号で、今週伸びているスタイル・色・ブランドを。
• ショップの商品ページを drape に共有すれば、買う前に似合うか確認できます。
• 英語・韓国語・日本語にスペイン語とフランス語が加わりました。
• スライドの連続ではなく、画面を指し示しながら案内するツアーに変わりました。
• クローゼットを二本指でサイズ変更、色・カテゴリ・着用回数で並べ替え、
  複数の服をまとめて登録できます。
```
