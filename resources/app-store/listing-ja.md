## App Store Connect

**名前** (≤30):

```
drape: クローゼットと試着
```

**サブタイトル** (≤30) — 名前にある *クローゼット* / *試着* は繰り返さず、新しい語を入れる:

```
AIスタイリストとコーデ記録
```

**プロモーションテキスト** (≤170 — ビルドなしで変更可能、キャンペーン用):

```
服を撮ってデジタルクローゼットを作り、着る前・買う前に自分の体で試着。AIスタイリストが手持ちの服だけでコーデを組みます。
```

**キーワード** — 変更しないでください。現在のライブ値がこのリポジトリにありません（ASC に直接入力）。
順位はキーワードごとに積み上がるため、何を置き換えるのか分からないまま差し替えると流入を失います。
必要な変更は一つだけです：新しいサブタイトル（`AIスタイリストとコーデ記録`）に含まれる語が
ライブのキーワードにあれば、それだけ外してください。名前・サブタイトル・キーワードは
まとめて索引されるため、重複は無駄です。ライブ値を `store-metadata.md` に控えておけば次回は困りません。

```
（ASC の現在の値を維持）
```

**説明** (≤4000):

```
ワードローブまるごと、手のひらに。

持っている服を1枚ずつ撮るだけで、drape が背景をきれいに消し、カテゴリー・色・季節まで自動で整理してデジタルクローゼットに。 全身写真が数枚あれば、AIバーチャル試着で何でも着られます。買う前に、着る前に — 本物の自分の顔と体にまとった姿を、先に確かめて。

気になる誰かのコーデ？ そのルックをまるごと自分の体に着せてみて。

• デジタルクローゼット — 撮るだけで、背景除去からカテゴリー・色・季節のタグ付けまで自動で。
• バーチャル試着 — 1点でもコーデ全体でも、顔とポーズをそのまま活かすAIで。
• AIスタイリスト — 手持ちの服だけでコーデを組む、自分専用のスタイリスト。
• OOTDカレンダー — 毎日の装いを記録して、自分だけのスタイルを積み重ねて。
• コーデ＆ボード — 服を組み合わせてルックを作り、ムードボードでインスピレーションを。
• トレンド — 毎週月曜の新しい号で、今週伸びているスタイル・色・ブランドを。

クローゼット、試着室、スタイル日記。すべては drape の中に。
```

**新機能** (≤4000) — 2.1.1:

```
• AIスタイリスト：4人から選ぶと、クローゼットからコーデを提案。
  ワンタップで自分の姿に試着できます。
• トレンド：毎週月曜の新しい号で、今週伸びているスタイル・色・ブランドを。
• ショップの商品ページを drape に共有すれば、買う前に似合うか確認できます。
• 英語・韓国語・日本語にスペイン語とフランス語が加わりました。
• スライドの連続ではなく、画面を指し示しながら案内するツアーに変わりました。
• クローゼットを二本指でサイズ変更、色・カテゴリ・着用回数で並べ替え、
  複数の服をまとめて登録できます。
```

## Google Play Console

```
drape: クローゼットと試着
```

**簡単な説明** (≤80):

```
クローゼットをデジタルに。AIで試着して、毎日のコーデを記録。
```

**詳しい説明** (≤4000) — 上の App Store 説明をそのまま使用。

App Store は 4000 字ですが **Play は 500 字**。同じ文を切ったものではなく、
項目を絞った別版です。弱い 2 項目は最後の 1 行にまとめています。

```

• スライドではなく画面を案内するツアーに。二本指でクローゼットのサイズ変更、新しい並べ替え、まとめて登録。
```

**新機能** (≤4000) — 2.2.0:

```
• 気になった着こなしが自分に似合うか、スタイリストに聞けます。試着が「どう見えるか」なら、これは「自分に合うか」を答えます。
• 販売中のアイテムは、着こなしの中で価格がそのまま見えます。タップしてアイテムを開き、出品者にメッセージを送れます。
• 自分の服でなくても試着できます。ウィッシュリストに保存されるので、後からまた探せます。
• 招待リンクがコードまで入力してくれます。6文字を書き写す必要はもうありません。
• フィルターのあるすべての画面に新しい順・古い順の並べ替えを追加 — コーデ、ボード、試着、クローゼット。
• 共有したアイテム・着こなしのリンクが開かない問題を修正しました。
```
