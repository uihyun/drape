## App Store Connect

**名前** (≤30):

```
drape: クローゼットと試着
```

**サブタイトル** (≤30) — 名前にある *クローゼット* / *試着* は繰り返さず、新しい語を入れる:

```
AIスタイリストとコーデ記録
```

**プロモーションテキスト** (≤170 — ビルドなしで変更可能、キャンペーン用):

```
服を撮ってデジタルクローゼットを作り、着る前・買う前に自分の体で試着。AIスタイリストが手持ちの服だけでコーデを組みます。
```

**キーワード** — 変更しないでください。現在のライブ値がこのリポジトリにありません（ASC に直接入力）。
順位はキーワードごとに積み上がるため、何を置き換えるのか分からないまま差し替えると流入を失います。
必要な変更は一つだけです：新しいサブタイトル（`AIスタイリストとコーデ記録`）に含まれる語が
ライブのキーワードにあれば、それだけ外してください。名前・サブタイトル・キーワードは
まとめて索引されるため、重複は無駄です。ライブ値を `store-metadata.md` に控えておけば次回は困りません。

```

```

**説明** (≤4000):

```
持っている服が、ぜんぶ見える。

全身写真を2〜3枚登録するだけ。買う前に、着る前に、自分の体で試着できます。手持ちの服は一着ずつ撮っておけば、背景を抜いてタグまで付け、自動で整理します。

着る前に、着てみる
• どんな服でも自分の写真の上で確認。モデルではなく自分の顔と体なので、似合うかどうかがそのまま分かります。
• 毎日5回無料。友達を招待すると、お互いに10回ずつ増えます。

クローゼットまるごとデジタルに
• 一着に一枚でOK。カテゴリ・色・季節・スタイルは自動で付きます。
• 忙しいときはコーデ写真を一枚。その中の服を一つずつ見つけます。
• タグ・ブランド・色で検索。二本指でサイズを変えて、ざっと見るか、じっくり見るか選べます。

自分専用のAIスタイリスト
• 手持ちの服だけでコーデを組みます。買い足す必要はありません。
• 好きなスタイルと苦手な色を伝えてください。伝えた好みが、推測より優先されます。
• 気に入ったコーデは保存して、いつでもまた試着できます。

一日一枚、OOTDカレンダー
• 写真を一枚撮れば、その日が記録されてカレンダーが埋まっていきます。
• よく着ている服と、すっかり忘れていた服が見えてきます。

トレンド
• 毎週月曜に新しい号。今週伸びているスタイル・色・ブランドを、メンバーが実際に着ている服から選びます。

他の人のクローゼットをのぞく
• トレンドで気になるコーデを開くと投稿者が分かり、その人のクローゼットをまるごと見られます。
• その服を自分に試着して、よければ保存。

drape は無料で始められます。試着は毎日回復する回数を使います。
```
